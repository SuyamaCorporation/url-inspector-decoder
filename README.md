## URL構造インスペクター＆デコーダー

URLを貼り付けるとスキーム/ホスト/パス/クエリパラメータ/フラグメントを色分け分解表示する開発支援ツール。

### 機能
- URL分解表示（スキーム・ホスト・ポート・パス・クエリ・フラグメントを色分けカード）
- クエリパラメータをkey=value表形式で表示・インライン編集→URL再組立てリアルタイム更新
- %エンコード/デコード双方向変換（個別テキスト用）
- 相対URL→絶対URL変換（ベースURL入力付き）
- URLの長さ・パラメータ数・エンコード文字数統計
- 各種コピーボタン

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- Web標準 URL API
- htmlEscape()によるXSS防止
